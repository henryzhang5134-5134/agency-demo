# 钱包去哪了

《请找到钱包》首案试玩，使用 Three.js、Rapier、TypeScript 与 Vite。棕色旅行箱内有 96 件物品／32 组，包含白熊视频演出、成对对白、钱包任务引导、弹性收集与三消动效。游戏名仍为《钱包去哪了》。

开场由箱盖遮住游戏区；任务卡飞入目标槽时开箱，再播放物件落入。手机使用满宽分区布局，视频与地板绑定缩放，收紧箱子、槽位和道具间距，为白熊脚部保留空间。

戏台通过两层 Canvas 显示解码后的视频帧，避免内置播放器按钮占据游戏画面；视频静音内联播放、不设置 autoplay 属性，由演出控制器调用播放。保留宿主就绪及前台恢复重试，明确的自动播放禁用在短暂重试后回退到场景图，不锁住任务。浏览器宿主或低电量模式仍可能限制播放，实际设备表现需真机验收。

开场使用 7.67 秒短版，手机视频位于 `public/video/web/`，960×540、无音轨、播放索引前置。六段运行视频合计约 17.74 MB；开场约 3.90 MB。较大的页面切图使用同尺寸 WebP，不在首屏抢先下载奖励弹窗；高分辨率手机的三消渲染倍率上限为 2。

槽位下方常驻“点击摇一摇”，代替组数显示。仅点击触发，不请求手机动作权限；物件加大幅度晃动并重新落位，保留数量、槽位与进度，优先露出可凑齐的同类。整理中短暂禁用拾取，含冷却和暂停保护。

## 本地运行

使用 Node.js 24，首次运行 `npm ci`，再运行 `npm run dev`。

`npm run build` 构建本地／域名根路径版本；`npm run build:github` 构建 `/agency-demo/` 子路径版本，输出 `dist-github/`。发布适配不更改画面、模型大小、物理参数或本地存档。

## GitHub Pages

仓库：`henryzhang5134-5134/agency-demo`。通过 GitHub Actions 自动检查、构建和发布 main 分支。试玩地址：https://henryzhang5134-5134.github.io/agency-demo/ 。最新发布状态以 Actions 为准。

通关后自动播放钱包交接、开门与奖励演出；“开启我的小店”暂时仅提示“建设中，敬请期待”，不进入主页。“通”为演示用一键通关，“重”为本局重开。进度仅保存在当前浏览器，不会同步到其他人的设备。首次点击后才可开启声音，视频加载速度取决于网络。0:00 后可继续游戏。
